# College Placement Management System

## Project Overview
The College Placement Management System is a database project developed using MySQL. It helps manage student information, company details, job applications, and placement records.

## Objective
The main objective of this project is to organize college placement data and generate useful placement reports using SQL queries.

## Technologies Used
- MySQL
- MySQL Workbench
- SQL

## Key Features
- Student information management
- Company details management
- Job application records
- Placement and selection tracking
- Department-wise placement reports
- Package-based placement analysis

## SQL Concepts Used
- CREATE and INSERT
- SELECT and WHERE
- JOINS
- GROUP BY and ORDER BY
- Aggregate Functions (SUM, AVG, COUNT)
- Subqueries

## Project Reports
- Total number of company applications
- Selected students
- Department-wise placement statistics
- Companies offering packages of 7 LPA or above
- Average placement package

## How to Run the Project
1. Open MySQL Workbench.
2. Open the downloaded SQL file.
3. Execute the SQL script.
4. Run the queries to view placement records and reports.
